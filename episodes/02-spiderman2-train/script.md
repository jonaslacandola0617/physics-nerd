## Numbers (checked off-screen, never shown as citations)
Assumptions (deliberately conservative): 4 cars × ~40 t loaded = **160 t**, **100 km/h** (27.8 m/s), stopped over **~300 m**.
- Kinetic energy: ½mv² ≈ **62 MJ**, about the energy in **15 kg of TNT**
- Average stopping force: 62 MJ ÷ 300 m ≈ 206 kN ≈ **21 tonnes-force**
- Per arm (two web lines): ≈ **10 tonnes-force**
- Deadlift world record ≈ 0.5 t, so each arm is doing about **20×** the record, the whole time
- Web line: if it's as strong as real spider silk (~1 GPa), each line only needs to be **about 1 cm thick** to hold that. The web is the believable part
- Passengers feel only ~0.13 g. The *gentle* stop is what keeps them safe
